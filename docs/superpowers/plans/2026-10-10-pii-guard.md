# pii-guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod that scans prompts, `@file` contents and (opt-in) `Read` results for PII and secrets, holds them behind a review pane with per-type allow/redact decisions, and is configurable through `/pii` and a model-callable `pii_patterns` tool.

**Architecture:** One hooks module (`hooks/register.tsx`) wires events to a pure scanner (`hooks/detect.ts` + `hooks/patterns.ts`), a store-backed config layer (`hooks/config.ts`) and a pane renderer (`hooks/review.tsx`). The `prompt.submit` hook awaits a module-level decision promise that the pane's buttons settle, then rewrites or drops the prompt. Session state lives in `$.state`, persistent config in `$.store`.

**Tech Stack:** Claude Code function-hook plugin API (build 2.1.295, `claude-code` types), TypeScript 5.4+, JSX against global `h`, `claude plugin validate` / `claude plugin test` for checks, `tsc -p` for types.

**Spec:** `docs/superpowers/specs/2026-10-10-pii-guard-design.md`

- `detect.ts` and `patterns.ts` import nothing from `claude-code`.
- `$.state` keys must be literal `{ plugin: 'pii-guard', key: '...' } as const` refs and declared in `types/index.d.ts`.
- Never log, toast or put in a tool result the matched PII value. Counts and type labels only.
- Default decision is `redact`. Fail closed: an unexpected error in the `prompt.submit` hook drops the prompt with a toast.
- Custom regex: flags forced to `giu`, source at most 500 chars, must compile, must pass the nested-quantifier lint.
- Scan input is capped at 200,000 characters per section.

- Run `claude plugin validate pii-guard` and `claude plugin test pii-guard` before every commit from Task 1 on; both must pass.

## Review Focus

Inputs the spec implies but no single requirement names. Each has a pinned test in the owning task.

1. **A prompt that is only a slash command** (`/help`, `/pii list`): must not open a review even if the command text happens to match a pattern. Owner: Task 6 (origin and text checks), test "ignores slash-command prompts".
2. **A prompt whose only finding is on the allowlist or a session-allowed type**: must pass without opening the pane and without a toast. Owner: Task 8, test "session allow passes silently".
3. **A custom regex that matches the empty string** (`a*`): must be rejected by `compilePattern`, otherwise `scan` loops forever on zero-width matches. Owner: Task 3, test "rejects a pattern that matches empty".
4. **A `@mention` that names a directory or a missing file**: must be skipped silently, not fail the prompt. Owner: Task 7, test "skips unreadable mentions".
5. **Escape or closing the pane by hand while a review is pending**: must drop the prompt, not leave the hook awaiting forever. Owner: Task 6, test "person closing the pane cancels".

```ts
import type { Category, PiiType, Validator } from '../types'

const digits = (s: string) => s.replace(/\D/g, '')

function luhn(value: string): boolean {
  const d = digits(value)
  if (d.length < 13 || d.length > 19) return false
  let sum = 0
  let dbl = false
  for (let i = d.length - 1; i >= 0; i--) {
    let n = Number(d[i])
    if (dbl) { n *= 2; if (n > 9) n -= 9 }
    sum += n
    dbl = !dbl
  }
  return sum % 10 === 0
}

function nhs(value: string): boolean {
  const d = digits(value)
  if (d.length !== 10) return false
  let sum = 0
  for (let i = 0; i < 9; i++) sum += Number(d[i]) * (10 - i)
  let check = 11 - (sum % 11)
  if (check === 11) check = 0
  if (check === 10) return false
  return check === Number(d[9])
}

function iban(value: string): boolean {
  const s = value.replace(/\s+/g, '').toUpperCase()
  if (!/^[A-Z]{2}\d{2}[A-Z0-9]{11,30}$/.test(s)) return false
  const rearranged = s.slice(4) + s.slice(0, 4)
  const numeric = rearranged.replace(/[A-Z]/g, ch => String(ch.charCodeAt(0) - 55))
  let remainder = 0
  for (const ch of numeric) remainder = (remainder * 10 + Number(ch)) % 97
  return remainder === 1
}
```

```ts
import type { Config, Decision, Finding, PiiType } from '../types'
import { VALIDATORS } from './patterns'

export const MAX_SCAN = 200_000
const MAX_PATTERN = 500

export type Compiled = { ok: true; regex: RegExp } | { ok: false; reason: string }

const NESTED_QUANTIFIER = /\((?:[^()\\]|\\.)*[*+]\s*(?:[^()\\]|\\.)*\)\s*[*+{]/
const ALTERNATION_IN_QUANTIFIED_GROUP = /\((?:[^()\\|]|\\.)*\|(?:[^()\\]|\\.)*\)\s*[*+{]/

export function compilePattern(source: string): Compiled {
  if (typeof source !== 'string' || source.length === 0) return { ok: false, reason: 'pattern is empty' }
  if (source.length > MAX_PATTERN) return { ok: false, reason: `pattern is longer than ${MAX_PATTERN} characters` }
  if (NESTED_QUANTIFIER.test(source)) return { ok: false, reason: 'a quantified group contains a quantifier (catastrophic backtracking risk), rewrite without nesting' }
  if (ALTERNATION_IN_QUANTIFIED_GROUP.test(source)) return { ok: false, reason: 'a quantified group contains alternation (catastrophic backtracking risk), make the branches mutually exclusive or drop the quantifier' }
  let regex: RegExp
  try { regex = new RegExp(source, 'giu') } catch (err) {
    return { ok: false, reason: `does not compile: ${(err as Error).message}` }
  }
  regex.lastIndex = 0
  if (regex.test('')) return { ok: false, reason: 'pattern matches the empty string' }
  return { ok: true, regex }
}

const compiledCache = new Map<string, RegExp | null>()
function compiled(source: string): RegExp | null {
  const hit = compiledCache.get(source)
  if (hit !== undefined) return hit
  const c = compilePattern(source)
  const r = c.ok ? c.regex : null
  compiledCache.set(source, r)
  return r
}

const escapeRe = (s: string) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')

export type ScanOptions = { sessionAllows?: readonly string[] }

function collect(regex: RegExp, text: string, type: PiiType, section: string, out: Finding[]) {
  regex.lastIndex = 0
  let m: RegExpExecArray | null
  while ((m = regex.exec(text)) !== null) {
    if (m[0].length === 0) { regex.lastIndex++; continue }
    out.push({ typeId: type.id, value: m[0], start: m.index, end: m.index + m[0].length, section })
  }
}

export function scan(text: string, section: string, config: Config, opts: ScanOptions = {}): Finding[] {
  const body = text.length > MAX_SCAN ? text.slice(0, MAX_SCAN) : text
  const allow = new Set(config.allowlist.map(s => s.trim().toLowerCase()))
  const skip = new Set(opts.sessionAllows ?? [])
  const raw: Finding[] = []
  for (const type of config.types) {
    if (!type.enabled || skip.has(type.id)) continue
    const validator = VALIDATORS[type.validator] ?? VALIDATORS.none
    const hits: Finding[] = []
    for (const src of type.patterns) {
      const re = compiled(src)
      if (re) collect(re, body, type, section, hits)
    }
    if (type.id === 'name') {
      for (const term of config.watchlist) {
        const trimmed = term.trim()
        if (!trimmed) continue
        const re = new RegExp(`(?<![\\p{L}\\p{N}])${escapeRe(trimmed)}(?![\\p{L}\\p{N}])`, 'giu')
        collect(re, body, type, section, hits)
      }
    }
    for (const h of hits) {
      if (!validator(h.value)) continue
      if (allow.has(h.value.trim().toLowerCase())) continue
      raw.push(h)
    }
  }
  raw.sort((a, b) => a.start - b.start || (b.end - b.start) - (a.end - a.start))
  const out: Finding[] = []
  let lastEnd = -1
  for (const f of raw) {
    if (f.start < lastEnd) continue
    out.push(f)
    lastEnd = f.end
  }
  return out
}

export type Numbering = Record<string, Record<string, number>>

export function placeholderFor(config: Config, typeId: string): string {
  return config.types.find(t => t.id === typeId)?.placeholder ?? typeId.toUpperCase()
}

export function redact(
  text: string,
  findings: Finding[],
  decisions: Record<string, Decision>,
  numbering: Numbering,
  placeholder: (typeId: string) => string = id => id.toUpperCase().replace(/[^A-Z0-9]/g, '_'),
): { text: string; numbering: Numbering; count: number } {
  const next: Numbering = Object.fromEntries(Object.entries(numbering).map(([k, v]) => [k, { ...v }]))
  const sorted = [...findings].filter(f => (decisions[f.typeId] ?? 'redact') === 'redact').sort((a, b) => a.start - b.start)
  let out = ''
  let cursor = 0
  let count = 0
  for (const f of sorted) {
    if (f.start < cursor) continue
    const byValue = (next[f.typeId] ??= {})
    const key = f.value.trim().toLowerCase()
    const n = byValue[key] ?? (byValue[key] = Object.keys(byValue).length + 1)
    out += text.slice(cursor, f.start) + `[${placeholder(f.typeId)}_${n}]`
    cursor = f.end
    count++
  }
  out += text.slice(cursor)
  return { text: out, numbering: next, count }
}

export function testPattern(source: string, samples: string[]) {
  const c = compilePattern(source)
  if (!c.ok) return c
  const matches = samples.map(sample => {
    const found: string[] = []
    c.regex.lastIndex = 0
    let m: RegExpExecArray | null
    while ((m = c.regex.exec(sample)) !== null) {
      if (m[0].length === 0) { c.regex.lastIndex++; continue }
      found.push(m[0])
    }
    return { sample, found }
  })
  return { ok: true as const, matches }
}
```

```ts
import type { EngineInterface } from 'claude-code'
import type { Config, PiiType } from '../types'
import { BUILTIN_TYPES, DEFAULT_ALLOWLIST } from './patterns'
import { compilePattern } from './detect'

export const STORE_KEY = 'config'
const configVersion = { plugin: 'pii-guard', key: 'configVersion' } as const

export function defaultConfig(): Config {
  return {
    version: 1,
    types: BUILTIN_TYPES.map(t => ({ ...t, patterns: [...t.patterns] })),
    watchlist: [],
    allowlist: [...DEFAULT_ALLOWLIST],
    scanToolReads: false,
  }
}

const isRecord = (v: unknown): v is Record<string, unknown> => typeof v === 'object' && v !== null
const strings = (v: unknown): string[] => Array.isArray(v) ? v.filter((x): x is string => typeof x === 'string') : []

function isCustomType(v: unknown): v is PiiType {
  return isRecord(v) && typeof v.id === 'string' && v.source === 'custom'
    && Array.isArray(v.patterns) && typeof v.placeholder === 'string'
}

export function mergeBuiltins(stored: unknown): Config {
  const base = defaultConfig()
  if (!isRecord(stored)) return base
  const storedTypes = Array.isArray(stored.types) ? stored.types : []
  const enabledById = new Map<string, boolean>()
  const custom: PiiType[] = []
  for (const t of storedTypes) {
    if (!isRecord(t) || typeof t.id !== 'string') continue
    if (t.source === 'custom') { if (isCustomType(t)) custom.push({ ...t, enabled: t.enabled !== false, category: 'custom', validator: 'none', source: 'custom', label: typeof t.label === 'string' ? t.label : t.id }) }
    else if (typeof t.enabled === 'boolean') enabledById.set(t.id, t.enabled)
  }
  return {
    version: 1,
    types: [
      ...base.types.map(t => ({ ...t, enabled: enabledById.get(t.id) ?? true })),
      ...custom,
    ],
    watchlist: strings(stored.watchlist),
    allowlist: 'allowlist' in stored ? strings(stored.allowlist) : base.allowlist,
    scanToolReads: stored.scanToolReads === true,
  }
}

export async function loadConfig($: EngineInterface): Promise<Config> {
  return mergeBuiltins(await $.store.get(STORE_KEY))
}

export async function saveConfig($: EngineInterface, config: Config): Promise<void> {
  await $.store.set(STORE_KEY, config)
  const { value = 0 } = await $.state.get(configVersion)
  await $.state.set(configVersion, value + 1)
}

type Outcome = { ok: true; config: Config } | { ok: false; reason: string }

const ID_RE = /^[a-z0-9][a-z0-9_-]{0,31}$/

export function addCustomType(config: Config, args: { id: string; label?: string; regex: string; placeholder?: string }): Outcome {
  const bare = (args.id ?? '').trim().toLowerCase().replace(/^custom:/, '')
  if (!ID_RE.test(bare)) return { ok: false, reason: 'id must be 1-32 of a-z, 0-9, _ or -' }
  const id = `custom:${bare}`
  if (config.types.some(t => t.id === id || t.id === bare)) return { ok: false, reason: `a type with id ${id} already exists` }
  const c = compilePattern(args.regex)
  if (!c.ok) return { ok: false, reason: c.reason }
  const placeholder = (args.placeholder ?? bare).toUpperCase().replace(/[^A-Z0-9]/g, '_')
  const type: PiiType = {
    id, label: args.label?.trim() || bare, category: 'custom', enabled: true, source: 'custom',
    patterns: [args.regex], validator: 'none', placeholder,
  }
  return { ok: true, config: { ...config, types: [...config.types, type] } }
}

export function removeType(config: Config, id: string): Outcome {
  const full = id.startsWith('custom:') ? id : `custom:${id}`
  const t = config.types.find(t => t.id === full)
  if (!t) return { ok: false, reason: `no custom type ${full}` }
  if (t.source !== 'custom') return { ok: false, reason: 'built-in types cannot be removed, turn them off instead' }
  return { ok: true, config: { ...config, types: config.types.filter(x => x.id !== full) } }
}

export function setEnabled(config: Config, id: string, enabled: boolean): Outcome {
  const match = config.types.find(t => t.id === id || t.id === `custom:${id}`)
  if (!match) return { ok: false, reason: `no type ${id}` }
  return { ok: true, config: { ...config, types: config.types.map(t => t.id === match.id ? { ...t, enabled } : t) } }
}

export function addTerm(config: Config, list: 'watchlist' | 'allowlist', term: string): Config {
  const t = term.trim()
  if (!t) return config
  const lower = t.toLowerCase()
  if (config[list].some(x => x.toLowerCase() === lower)) return config
  return { ...config, [list]: [...config[list], list === 'allowlist' ? lower : t] }
}

export function removeTerm(config: Config, list: 'watchlist' | 'allowlist', term: string): Config {
  const lower = term.trim().toLowerCase()
  return { ...config, [list]: config[list].filter(x => x.toLowerCase() !== lower) }
}
```

```tsx
  send(): void
  cancel(): void

  closeSettings(): void

const CONTEXT_LINES = 3
const TRIM_OVER_LINES = 40

type Run = { text: string; finding?: Finding }

function runs(section: ReviewSection, findings: Finding[]): Run[] {
  const mine = findings.filter(f => f.section === section.id).sort((a, b) => a.start - b.start)
  const out: Run[] = []
  let cursor = 0
  for (const f of mine) {
    if (f.start > cursor) out.push({ text: section.text.slice(cursor, f.start) })
    out.push({ text: section.text.slice(f.start, f.end), finding: f })
    cursor = f.end
  }
  if (cursor < section.text.length) out.push({ text: section.text.slice(cursor) })
  return out
}

function trimLines(section: ReviewSection, findings: Finding[]): { text: string; offset: number }[] {
  const lines = section.text.split('\n')
  if (lines.length <= TRIM_OVER_LINES) return [{ text: section.text, offset: 0 }]
  const starts: number[] = []
  let pos = 0
  for (const l of lines) { starts.push(pos); pos += l.length + 1 }
  const keep = new Set<number>()
  for (const f of findings.filter(f => f.section === section.id)) {
    let line = starts.findIndex((s, i) => f.start >= s && (i + 1 >= starts.length || f.start < starts[i + 1]!))
    if (line < 0) line = 0
    for (let i = Math.max(0, line - CONTEXT_LINES); i <= Math.min(lines.length - 1, line + CONTEXT_LINES); i++) keep.add(i)
  }
  const windows: { text: string; offset: number }[] = []
  let i = 0
  while (i < lines.length) {
    if (!keep.has(i)) { i++; continue }
    const from = i
    while (i < lines.length && keep.has(i)) i++
    windows.push({ text: lines.slice(from, i).join('\n'), offset: starts[from]! })
  }
  return windows
}

function sectionBlock(E: E, section: ReviewSection, findings: Finding[], config: Config) {
  const { Box, Text } = E
  const windows = trimLines(section, findings)
  const trimmed = windows.length > 1 || (windows[0] && windows[0].text.length < section.text.length)
  return (
    <Box flexDirection="column" marginBottom={1}>
      <Text bold>{section.title}{section.truncated ? '  (scan capped at 200,000 characters)' : ''}{trimmed ? `  (showing context around findings, ${section.text.split('\n').length} lines)` : ''}</Text>
      {windows.map((w, wi) => {
        const sub: ReviewSection = { id: section.id, title: section.title, text: w.text }
        const shifted = findings.filter(f => f.section === section.id && f.start >= w.offset && f.end <= w.offset + w.text.length)
          .map(f => ({ ...f, start: f.start - w.offset, end: f.end - w.offset }))
        return (
          <Box flexDirection="column">
            {wi > 0 && <Text dimColor>…</Text>}
```

```tsx
import { read, update } from 'claude-code'
import type { Register, EngineInterface } from 'claude-code'
import type { Config, Decision } from '../types'
import { loadConfig, saveConfig, setEnabled, removeType as removeTypeFrom, addTerm as addTermTo, removeTerm as removeTermFrom } from './config'
import { PANE_ID, reviewAtom, sessionAllowsAtom, settingsOpenAtom, renderReview, renderSettings } from './review'
import type { PaneActions } from './review'

type Outcome = 'send' | 'cancel'
let pending: ((o: Outcome) => void) | null = null
const settle = (o: Outcome) => { const p = pending; pending = null; p?.(o) }

function actionsFor($: EngineInterface): PaneActions {
  const edit = async (fn: (c: Config) => Config) => saveConfig($, fn(await loadConfig($)))
  return {
    decide: (typeId, d: Decision) => void update($, reviewAtom, r => r ? { ...r, decisions: { ...r.decisions, [typeId]: d } } : r),
    send: () => settle('send'),
    cancel: () => settle('cancel'),
    openSettings: () => void update($, settingsOpenAtom, () => true),
    closeSettings: () => void (async () => {
      await update($, settingsOpenAtom, () => false)
      if (!(await read($, reviewAtom))) await $.ui.close({ id: PANE_ID })
    })(),
    toggleType: (id, on) => void edit(c => { const r = setEnabled(c, id, on); return r.ok ? r.config : c }),
    removeType: id => void edit(c => { const r = removeTypeFrom(c, id); return r.ok ? r.config : c }),
    addTerm: (list, term) => void edit(c => addTermTo(c, list, term)),
    removeTerm: (list, term) => void edit(c => removeTermFrom(c, list, term)),
    setScanReads: on => void edit(c => ({ ...c, scanToolReads: on })),
    revokeSessionAllow: id => void update($, sessionAllowsAtom, l => l.filter(x => x !== id)),
  }
}

export const register: Register = on => {
  on('session.start', async ($, e, next) => next(e))

  on('ui.render', { component: 'Pane', requestId: PANE_ID }, async ($, e) => {
    const E = $.ui.resolve(e)
    const [review, allows, settingsOpen, config] = await Promise.all([
      read($, reviewAtom), read($, sessionAllowsAtom), read($, settingsOpenAtom), loadConfig($),
    ])
    await $.state.get({ plugin: 'pii-guard', key: 'configVersion' })
    const actions = actionsFor($)
    if (settingsOpen || !review || review.view === 'settings') {
      return renderSettings(E, config, allows, review !== null, actions, e.surface)
    }
    return renderReview(E, review, config, actions, e.props.bodyColumns)
  })
}
```

```tsx
import { scan, redact, placeholderFor, MAX_SCAN } from './detect'
import type { Numbering } from './detect'
import type { Finding, Review, ReviewSection, Unscannable } from '../types'

let reviewSeq = 0

function buildReview(kind: Review['kind'], sections: ReviewSection[], findings: Finding[], unscannable: Unscannable[]): Review {
  return { id: `r${++reviewSeq}`, kind, sections, findings, unscannable, decisions: {}, view: 'review' }
}

function sectionOf(id: string, title: string, text: string): ReviewSection {
  return text.length > MAX_SCAN ? { id, title, text, truncated: true } : { id, title, text }
}

async function runReview($: EngineInterface, review: Review): Promise<{ outcome: Outcome; decisions: Record<string, Decision> }> {
  settle('cancel')  // a stale pending review loses
  await update($, settingsOpenAtom, () => false)
  await update($, reviewAtom, () => review)
  const outcomeP = new Promise<Outcome>(resolve => { pending = resolve })
  const opened = await $.ui.open({ id: PANE_ID, title: review.kind === 'tool' ? 'PII review (Read)' : 'PII review', focus: true, closeOnEscape: true, holdToasts: true, rows: 24 })
  if (!opened.isPlaced) {
    const answer = await $.ui.ask(
      `pii-guard found ${review.findings.length} PII value(s). The review pane could not be shown (${opened.reason}). What now?`,
      ['Redact all and continue', 'Cancel'],
    ).catch(() => 'Cancel')
    settle(answer === 'Redact all and continue' ? 'send' : 'cancel')
  }
  const outcome = await outcomeP
  const final = (await read($, reviewAtom)) ?? review
  await update($, reviewAtom, () => null)
  await $.ui.close({ id: PANE_ID }).catch(() => undefined)
  if (outcome === 'send') {
    const allows = Object.entries(final.decisions).filter(([, d]) => d === 'allow-session').map(([id]) => id)
    if (allows.length) await update($, sessionAllowsAtom, l => [...new Set([...l, ...allows])])
  }
  return { outcome, decisions: final.decisions }
}

function redactAll(findings: Finding[]): Record<string, Decision> {
  return Object.fromEntries(findings.map(f => [f.typeId, 'redact' as const]))
}
```

```tsx
async function mentionedFiles($: EngineInterface, text: string): Promise<{ path: string; text: string }[]> {
  const out: { path: string; text: string }[] = []
```

```tsx
function scanAgainst(text: string, entry: { findings: Finding[] }): Finding[] {
  const out: Finding[] = []
  for (const f of entry.findings) {
    let from = 0
    for (;;) {
      const at = text.indexOf(f.value, from)
      if (at < 0) break
      out.push({ ...f, start: at, end: at + f.value.length })
      from = at + f.value.length
    }
  }
  return out.sort((a, b) => a.start - b.start)
}
```

```ts
import type { EngineInterface } from 'claude-code'
import { loadConfig, saveConfig, addCustomType, removeType, setEnabled, addTerm, removeTerm } from './config'
import { scan, testPattern } from './detect'

const USAGE = [
  'Usage:',
  '  /pii                      open settings',
  '  /pii list                 list types, watchlist and allowlist counts',
  '  /pii on <id> | off <id>   toggle a type',
  '  /pii add <id> <regex>     add a custom type (flags giu are applied)',
  '  /pii rm <id>              remove a custom type',
  '  /pii watch <term> | unwatch <term>',
  '  /pii allow <term> | unallow <term>',
  '  /pii test <id|regex> <sample text>',
  '  /pii reads on|off         scan Read tool results',
].join('\n')

export async function runPiiCommand($: EngineInterface, args: string): Promise<{ text?: string; openSettings?: true }> {
  const trimmed = args.trim()
  if (!trimmed) return { openSettings: true }
  const [sub = '', ...rest] = trimmed.split(/\s+/)
  const restText = trimmed.slice(sub.length).trim()
  const config = await loadConfig($)
  const commit = async (c: typeof config, text: string) => { await saveConfig($, c); return { text } }

  switch (sub) {
    case 'list': {
      const rows = config.types.map(t => `  ${t.id.padEnd(22)} ${t.enabled ? 'on ' : 'off'}  ${t.label}${t.source === 'custom' ? `  /${t.patterns[0]}/` : ''}`)
      return { text: ['Types:', ...rows, `watchlist: ${config.watchlist.length}, allowlist: ${config.allowlist.length}, scan Read results: ${config.scanToolReads ? 'on' : 'off'}`].join('\n') }
    }
    case 'on': case 'off': {
      const r = setEnabled(config, rest[0] ?? '', sub === 'on')
      return r.ok ? commit(r.config, `${rest[0]} is now ${sub}`) : { text: r.reason }
    }
    case 'add': {
      const id = rest[0] ?? ''
      const regex = restText.slice(id.length).trim()
      if (!id || !regex) return { text: USAGE }
      const r = addCustomType(config, { id, regex })
      return r.ok ? commit(r.config, `added custom:${id.replace(/^custom:/, '')} as /${regex}/giu, enabled`) : { text: `not added: ${r.reason}` }
    }
    case 'rm': {
      const r = removeType(config, rest[0] ?? '')
      return r.ok ? commit(r.config, `removed ${rest[0]}`) : { text: r.reason }
    }
    case 'watch': return commit(addTerm(config, 'watchlist', restText), `watching "${restText}"`)
    case 'unwatch': return commit(removeTerm(config, 'watchlist', restText), `no longer watching "${restText}"`)
    case 'allow': return commit(addTerm(config, 'allowlist', restText), `"${restText.toLowerCase()}" will not be reported`)
    case 'unallow': return commit(removeTerm(config, 'allowlist', restText), `"${restText.toLowerCase()}" removed from allowlist`)
    case 'reads': {
      if (rest[0] !== 'on' && rest[0] !== 'off') return { text: USAGE }
      return commit({ ...config, scanToolReads: rest[0] === 'on' }, `scan Read results: ${rest[0]}`)
    }
    case 'test': {
      const target = rest[0] ?? ''
      const sample = restText.slice(target.length).trim()
      if (!target || !sample) return { text: USAGE }
      const type = config.types.find(t => t.id === target || t.id === `custom:${target}`)
      if (type) {
        const found = scan(sample, 'test', { ...config, types: [{ ...type, enabled: true }] })
        return { text: `${found.length} match${found.length === 1 ? '' : 'es'} for ${type.id}${found.length ? ': ' + found.map(f => f.value).join(', ') : ''}` }
      }
      const r = testPattern(target, [sample])
      if (!r.ok) return { text: `pattern rejected: ${r.reason}` }
      const found = r.matches[0]?.found ?? []
      return { text: `${found.length} match${found.length === 1 ? '' : 'es'} for /${target}/giu${found.length ? ': ' + found.join(', ') : ''}` }
    }
    default: return { text: USAGE }
  }
}
```

`/pii test` prints the matched values on purpose: the user typed the sample themselves and asked to see what matches. Nothing else in the mod prints values.

```ts
      placeholder: { type: 'string', description: 'redaction tag for add, e.g. REF -> [REF_1]' },
      samples: { type: 'array', items: { type: 'string' }, description: 'sample strings for test' },
      term: { type: 'string', description: 'term for watch/unwatch/allow/unallow' },
      enabled: { type: 'boolean', description: 'for toggle' },
    },
    required: ['action'],
  },
  isDeferred: false,
}

const str = (v: unknown) => typeof v === 'string' ? v : undefined

export async function runPatternsTool($: EngineInterface, input: Record<string, unknown>): Promise<{ ok: boolean; message: string; data?: unknown }> {
  const action = str(input.action)
  const config = await loadConfig($)
  const save = async (c: typeof config, message: string, data?: unknown) => { await saveConfig($, c); return { ok: true, message, data } }
  switch (action) {
    case 'list':
      return { ok: true, message: `${config.types.length} types`, data: {
        types: config.types.map(t => ({ id: t.id, label: t.label, category: t.category, enabled: t.enabled, source: t.source, placeholder: t.placeholder, patterns: t.source === 'custom' ? t.patterns : undefined })),
        watchlist: config.watchlist, allowlist: config.allowlist, scanToolReads: config.scanToolReads,
      } }
    case 'test': {
      const samples = Array.isArray(input.samples) ? input.samples.filter((s): s is string => typeof s === 'string') : []
      if (samples.length === 0) return { ok: false, message: 'samples required' }
      const id = str(input.id)
      const type = id ? config.types.find(t => t.id === id || t.id === `custom:${id}`) : undefined
      const sources = type ? type.patterns : str(input.regex) ? [str(input.regex)!] : []
      if (sources.length === 0) return { ok: false, message: 'give regex or a known id' }
      const merged = samples.map(sample => ({ sample, found: [] as string[] }))
      for (const src of sources) {
        const r = testPattern(src, samples)
        if (!r.ok) return { ok: false, message: `pattern rejected: ${r.reason}` }
        r.matches.forEach((m, i) => merged[i]!.found.push(...m.found))
      }
      return { ok: true, message: `${merged.filter(m => m.found.length).length} of ${samples.length} samples matched`, data: merged }
    }
    case 'add': {
      const id = str(input.id), regex = str(input.regex)
      if (!id || !regex) return { ok: false, message: 'id and regex required' }
      const r = addCustomType(config, { id, regex, label: str(input.label), placeholder: str(input.placeholder) })
      return r.ok ? save(r.config, `added custom:${id.replace(/^custom:/, '')}, enabled`) : { ok: false, message: r.reason }
    }
    case 'remove': {
      const r = removeType(config, str(input.id) ?? '')
      return r.ok ? save(r.config, `removed ${input.id}`) : { ok: false, message: r.reason }
    }
    case 'toggle': {
      if (typeof input.enabled !== 'boolean') return { ok: false, message: 'enabled (boolean) required' }
      const r = setEnabled(config, str(input.id) ?? '', input.enabled)
      return r.ok ? save(r.config, `${input.id} ${input.enabled ? 'enabled' : 'disabled'}`) : { ok: false, message: r.reason }
    }
    case 'watch': case 'unwatch': case 'allow': case 'unallow': {
      const term = str(input.term)
      if (!term) return { ok: false, message: 'term required' }
      const list = action.endsWith('watch') ? 'watchlist' : 'allowlist'
      const c = action.startsWith('un') ? removeTerm(config, list, term) : addTerm(config, list, term)
      return save(c, `${action}: ${list} now has ${c[list].length} entries`)
    }
    default: return { ok: false, message: 'unknown action; use list, test, add, remove, toggle, watch, unwatch, allow, unallow' }
  }
}
```

```markdown
# pii-guard

A Claude Code mod that holds prompts containing PII or secrets behind a review pane before they reach the model.

## What it scans

- The prompt as typed, pastes included.
- Files pulled in with `@path`, shown as their own sections in the same review.
- Optionally (off by default) the content the `Read` tool returns, mid-turn.
- Images, PDFs and audio cannot be scanned (the mod never sees their bytes). They are listed in the review so you can Send or Cancel knowingly.

## The review

Each detected type gets a row: **Allow once**, **Allow this session**, **Redact** (the default). Send applies the choices; Cancel or Escape drops the prompt. Redacted values become numbered placeholders, `[EMAIL_1]`, `[CARD_2]`, the same value always getting the same number within one review, so Claude can still reason about "the second email".

In a headless `claude -p` run there is nobody to ask, so everything flagged is redacted and the run continues.

## Built-in types

email, phone, UK postcode, NI number, NHS number (mod-11 checked), passport, UK driving licence, payment card (Luhn checked), IBAN (mod-97 checked), UK sort code + account, US SSN, IP address, date of birth, API keys and secrets, health terms, personal names (watchlist plus a capitalised-pair heuristic filtered by an allowlist). All start enabled.

## Configuration

- `/pii` opens the settings pane: toggle types, edit the names watchlist and the allowlist, turn Read scanning on.
- `/pii add <id> <regex>` adds a custom type; `/pii test <id|regex> <sample>` tries one.
- Ask Claude: "add a pattern for our internal ticket ids like REF-123456". It uses the `pii_patterns` tool to test the regex against samples and add it. The addition shows as a normal tool call you approve.

Config is stored in the mod's own store file under your Claude configuration directory. The watchlist holds names, which are themselves personal data: keep that directory private.

## Developing

Source lives in this repo. Load it for a session with:

    claude --plugin-dir "E:\LLM Config\Mods\pii-guard"

Checks:

    claude plugin validate pii-guard
    npx -y -p typescript@5.6 tsc -p pii-guard
    claude plugin test pii-guard

## Not in v1

Subagent prompts, Bash and Grep output, per-project configuration, image or PDF content scanning. See `docs/superpowers/specs/2026-10-10-pii-guard-design.md`, section "v2 backlog".
```
